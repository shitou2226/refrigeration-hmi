# 验证记录

2026-10-12，在 Windows 本机使用 .NET SDK 9.0.317 验证。Release 构建结果为 0 警告、0 错误，19 项自动检查通过。

|范围|检查内容|
|---|---|
|采集|正常样本入库、循环采集、停止取消、采集失败后的质量和报警|
|数据库|重新打开后数据保留、采集与报警事务回滚、数据库故障上报并停止采集|
|报警|持续超限去重、恢复回差、确认不解除故障、恢复后再次触发、重启载入活动状态|
|导出|CSV 转义、界面限制 5,000 条时仍能完整导出 5,101 条|
|Modbus|分片报文、负温度解码、异常响应拒绝、断线不产生有效样本|
|界面线程|启动、读取及停止 TCP 模拟器时不死锁|

实际窗口中操作了四个页面，核对实时刷新、趋势、故障触发、报警确认及恢复、历史查询、CSV 导出、保存参数、暂停和退出。

一次 CSV 导出得到 371 条记录，包含模拟源和本机 TCP 源，其中 64 条为通信失败记录；这些记录的数值字段全部为空。TCP 模式中的延迟来自实际报文往返，受电脑负载影响。

修复过高 DPI 下的标题、数值与表格截断，以及停止内置模拟器时捕获界面同步上下文导致的卡住问题。最终版本已重新检查参数保存、停止模拟器和退出。

这些结果对应本机模拟器、通信客户端与 SQLite。没有验证实物传感器、PLC、RS485、现场网络或制冷机组的控制保护。
