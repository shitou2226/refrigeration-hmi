# 试用 制冷上位机

C# 采集、趋势、报警与 SQLite；模拟值和本机 Modbus TCP，尚未接实际机组。

## 试一遍

1. 启动后观察模拟采集、趋势和数据库记录数。
2. 触发排气高压，确认报警，再切回正常查看恢复。
3. 启动本机 TCP 模拟器，切换数据源，停止再启动模拟器。
4. 查询 Bad 质量历史并导出 CSV，核对断线记录的数值为空。
