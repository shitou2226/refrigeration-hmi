# 依赖许可证

部分 NuGet 包在元数据中声明许可证表达式，没有把正文作为独立文件打包。便携构建使用这里的上游原文补齐：

- `Microsoft.Data.Sqlite-MIT.txt`：[dotnet/efcore v10.0.12](https://github.com/dotnet/efcore/blob/v10.0.12/LICENSE.txt)
- `SQLitePCLRaw-Apache-2.0.txt`：[ericsink/SQLitePCL.raw v2.1.12](https://github.com/ericsink/SQLitePCL.raw/blob/v2.1.12/LICENSE.TXT)

其他依赖与 .NET 运行时的许可从实际还原的包中复制。版本和用途见项目根目录 `THIRD_PARTY_NOTICES.md`。
